# SRAI Publication, Teaching, and Outreach Release

This directory is the operational release kit for the validated SRAI
curriculum. It converts the 200 executable notebooks and nine-book catalog
into materials that can be published, taught, demonstrated, and governed.

## Release contents

- `CURRICULUM_PATHWAYS.md`: recommended learning sequences and prerequisites.
- `INSTRUCTOR_GUIDE.md`: repeatable course-delivery and assessment guidance.
- `PUBLICATION_CHECKLIST.md`: quality and rights gate before public release.
- `OUTREACH_KIT.md`: launch copy, demonstrations, and communication calendar.
- `RELEASE_MANIFEST.json`: machine-readable scope and validation statement.
- `catalog.csv`: one row per active notebook, generated from Studio.

## Verified baseline

- 9 curriculum books
- 200 active notebooks
- 200 notebooks executed successfully
- 0 execution failures
- Historical variants retained outside the active catalog

The canonical evidence is `../reports/final_execution_report.json`.
