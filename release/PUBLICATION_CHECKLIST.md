# SRAI Publication Checklist

## Gate 1 — Technical integrity

- [x] Nine active package namespaces compile.
- [x] Active catalog contains 200 notebooks.
- [x] All 200 notebooks execute successfully.
- [x] Historical variants are excluded from the active catalog.
- [x] Automated Studio tests pass.
- [ ] Re-run validation on the target publication infrastructure.

## Gate 2 — Editorial quality

- [ ] Confirm final volume titles and author/editor credits.
- [ ] Apply a consistent chapter and notebook naming convention.
- [ ] Proofread introductions, explanations, exercises, and references.
- [ ] Verify that figures, tables, and equations render correctly.
- [ ] Add accessibility text for meaningful figures.
- [ ] Confirm links and citations.

## Gate 3 — Rights and data

- [ ] Select and publish the content license.
- [ ] Select and publish the software-code license.
- [ ] Confirm rights for every external image, quotation, and dataset.
- [ ] Remove credentials, personal data, and confidential institutional data.
- [ ] Add acknowledgements and third-party notices.

## Gate 4 — Teaching release

- [x] Define curriculum pathways.
- [x] Define the standard session model.
- [x] Define assessment weights and capstone rubric.
- [ ] Pilot at least one pathway with a small cohort.
- [ ] Record learner feedback and corrective actions.

## Gate 5 — Public launch

- [x] Prepare launch positioning and sample announcements.
- [x] Define demonstration sequence and communication calendar.
- [ ] Select the canonical public repository and publication URLs.
- [ ] Publish release notes, checksum, and known limitations.
- [ ] Establish issue reporting and maintenance ownership.

Public release is authorized only when all unchecked rights, editorial, pilot,
and infrastructure items have accountable owners and due dates.
