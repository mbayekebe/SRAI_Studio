# Market Prices With Context — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Market Prices With Context** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Teaching sequence


## Worked example
A maize price alert distinguishes wholesale from retail prices and standardizes package units before comparing markets.

## Safeguard
Price comparisons can be false when grades, units, transaction levels, seasons, or market access conditions differ. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
