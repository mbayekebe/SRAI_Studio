# Earn the Model’s Complexity — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Earn the Model’s Complexity** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Worked example
A seasonal regression is compared with last-value, seasonal-history, and trend baselines using time-ordered holdouts and interval coverage.

## Safeguard
Random splitting, weak baselines, and point estimates can create impressive results that fail under real forecasting conditions. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
