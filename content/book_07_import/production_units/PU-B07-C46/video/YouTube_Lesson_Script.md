# Anomaly Is Not Guilt — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Anomaly Is Not Guilt** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Teaching sequence


## Worked example
An assessment authority examines unusual answer patterns with administration records and independent review before drawing any conclusion.

## Safeguard
Automated anomaly detection can wrongly accuse learners or schools when similarity, context, data quality, and alternative explanations are ignored. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
