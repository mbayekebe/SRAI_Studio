# Distance Is Not Access — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Distance Is Not Access** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Teaching sequence


## Worked example
Two communities at equal distance have different access because roads, transport cost, opening hours, and service readiness differ.

## Safeguard
Straight-line distance can create a false picture of access and hide systematic exclusion. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
