# Plan Seats Before Crowding Arrives — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Plan Seats Before Crowding Arrives** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Teaching sequence


## Worked example
A planning team tests demand scenarios before expanding classrooms or changing catchment arrangements.

## Safeguard
Single-point forecasts can create stranded capacity, overcrowding, or unequal access when migration and uncertainty are ignored. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
