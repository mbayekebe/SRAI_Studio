# Start With the Decision — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Start With the Decision** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Worked example
An attendance early-warning service identifies cases for authorized review; it does not impose sanctions or determine eligibility.

## Safeguard
A technically accurate signal can still be unusable when nobody has authority, time, capacity, or a lawful intervention. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
