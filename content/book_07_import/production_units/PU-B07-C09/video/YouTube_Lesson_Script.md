# Core Agricultural Indicators With Denominators — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Core Agricultural Indicators With Denominators** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Teaching sequence


## Worked example
A crop-loss rate identifies affected hectares as the numerator and assessed planted hectares—not all land—as the denominator.

## Safeguard
Indicators without defensible denominators invite false comparisons across crops, districts, seasons, and reporting systems. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
