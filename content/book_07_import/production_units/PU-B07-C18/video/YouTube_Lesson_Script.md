# Count Herds, Understand Systems — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Count Herds, Understand Systems** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Teaching sequence


## Worked example
A livestock indicator distinguishes herd size from livestock-owning households and records transhumant mobility and reference season.

## Safeguard
Animal counts alone can conceal mobility, ownership concentration, production purpose, mortality, and seasonal availability. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
