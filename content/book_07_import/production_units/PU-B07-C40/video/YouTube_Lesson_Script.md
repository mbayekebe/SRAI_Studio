# Put Learning Inputs Where They Can Be Used — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Put Learning Inputs Where They Can Be Used** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Teaching sequence


## Worked example
A district reconciles enrolment, stock, curriculum, and delivery evidence before authorizing redistribution.

## Safeguard
Procurement counts can appear successful while materials remain mismatched, delayed, inaccessible, or unused. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
