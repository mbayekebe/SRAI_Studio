# Outbreak Signals Before Alarm — Video Lesson Script

## Opening
What decision are we trying to improve, who owns it, and what must remain under human authority? This lesson uses **Outbreak Signals Before Alarm** to make that question operational.

## Learning promise
By the end, learners can explain the core contract, test it using the notebook, identify failure conditions, and state when the system must abstain.

## Teaching sequence


## Worked example
A syndromic signal exceeding a seasonal baseline is corroborated across facilities before epidemiological review.

## Safeguard
Premature alarms can cause panic, while delayed escalation can allow a genuine outbreak to spread. The model supports review; the accountable institution retains authorization and action.

## Closing challenge
Ask learners to rewrite the example for another sector while preserving evidence, uncertainty, abstention, escalation, and human authority.
